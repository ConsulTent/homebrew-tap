# ConsulTent Homebrew Tap

Homebrew tap for [ConsulTent](https://github.com/ConsulTent) software.

## Install

```
brew install ConsulTent/tap/mcpcli
```

Installs the `mcp` binary — an MCP (Model Context Protocol) client and inspector
CLI. Upstream: https://github.com/ConsulTent/mcpcli
